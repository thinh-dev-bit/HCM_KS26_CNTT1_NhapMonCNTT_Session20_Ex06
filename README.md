Dự án Thương mại điện tử mẫu tuân thủ nghiêm ngặt các tiêu chuẩn an toàn thông tin (Session 18).

## Hướng dẫn cài đặt
1. Clone repository về máy.
2. Chạy `npm install`.
3. Copy file `.env.example` thành `.env` và điền các giá trị thực tế ở local.
4. Chạy `npm start` hoặc `npm run dev`.

## Cảnh báo Bảo mật
Vui lòng đọc kỹ file `SECURITY.md` trước khi thực hiện bất kỳ lệnh `git push` nào.
